**Hostel** — это полнофункциональное приложение для поиска и бронирования отелей, разработанное на Kotlin с использованием Jetpack Compose. Проект объединяет в себе все лабораторные работы и представляет собой готовый коммерческий продукт.

---

## 📱 Основные возможности

### Для Гостя (USER)
*   **Поиск отелей**: Выбор города, даты (через кастомный горизонтальный календарь) и количества гостей.
*   **Бронирование**: Оформление заявки с автоматическим расчетом итоговой стоимости (зависит от количества ночей).
*   **Колесо Фортуны**: Интерактивная мини-игра для получения скидки (5-20%) на бронирование.
*   **Отзывы и рейтинг**: Возможность оставить отзыв и оценку (1-5). Средний рейтинг отеля пересчитывается автоматически.
*   **Управление бронями**: Просмотр активных заявок и истории. Отмена брони.

### Для Менеджера (MANAGER)
*   **Панель заявок**: Просмотр всех бронирований в системе.
*   **Управление статусами**: Возможность подтвердить заселение («Услуга оказана») или отметить, что гость не приехал («Не заселился»).

### Для Администратора (ADMIN)
*   **Все права менеджера**: Управление всеми заявками.
*   **Управление пользователями**: Просмотр базы клиентов, их ролей, потраченных сумм и удаление аккаунтов.
*   **Добавление отелей**: Создание новых отелей с указанием цены, рейтинга и выбором удобств (Wi-Fi, Бассейн и т.д.).
*   **Аналитика**: Отображение общей выручки по завершенным бронированиям.

## 🛡️ Безопасность (Hardening)

В рамках лабораторной работы по аудиту (Laba 16) были внедрены механизмы защиты:
1.  **Запрет Cleartext (HTTP)**: В `network_security_config.xml` разрешен только HTTPS.
2.  **Шифрование данных**: Пароли и брони хранятся в `EncryptedSharedPreferences` (AndroidKeyStore).
3.  **Обфускация кода**: Включен `R8` (minifyEnabled) для защиты от реверс-инжиниринга.
4.  **Двухфакторная аутентификация (2FA)**: Вход в приложение подтверждается Push-уведомлением с кодом.
5.  **Ролевая модель (RBAC)**: Строгое разграничение прав доступа (UI скрывает недоступные функции, логика блокирует действия).

## 🛠 Технологический стек

*   **Язык**: Kotlin 2.0+
*   **UI**: Jetpack Compose (Material 3), Navigation Compose
*   **Архитектура**: State Hoisting, `remember`, `SharedPreferences` (JSON)
*   **Сеть**: Retrofit 2, OkHttp, Gson (для загрузки данных)
*   **Безопасность**: EncryptedSharedPreferences, BiometricPrompt
*   **Графика**: Градиенты, анимации `Animatable`, `AnimatedVisibility`
